# Telegram Post Generation Rules for @gastroconnect

- **Style**: Ultra-punchy, high-contrast, zero fluff or AI generic text.
- **Structure**:
  1. Emoji + Bold Role / Restaurant Name
  2. 💰 Bold Salary / Rate
  3. 📍 Metro / Location
  4. ⏰ Schedule / Shift hours
  5. 🎁 Perks / Conditions in 1 concise line
  6. 📞 Direct phone number and Telegram handle
- **Links**: Clean URLs only (`https://gastroconnect.ru/workers/` and `https://t.me/gastroconnect`).
- **No Web Page Previews**: Web link previews must always be disabled (`disable_web_page_preview: true`).
